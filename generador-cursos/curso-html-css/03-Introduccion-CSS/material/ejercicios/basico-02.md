# 🟢 Básico 02 — ¿Qué regla gana?

> 🟢 **Nivel:** Básico · 🎓 **Resultados de aprendizaje:** RA-4, RA-5

## 🧱 Estado inicial

Abrí [`basico-02.html`](../recursos/portafolio-inicial/basico-02.html) y su hoja
[`basico-02.css`](../recursos/portafolio-inicial/css/basico-02.css), de la carpeta `portafolio-inicial`. La hoja de Mateo tiene
estas reglas para el color del texto:

| Selector | Color |
|---|---|
| `p` | `#111827` (gris oscuro) |
| `h2` | `#16a34a` (verde) |
| `.oferta` | `#b45309` (ocre) |
| `#especial` | `#7c3aed` (violeta) |
| `.aviso` (primera regla) | `#0891b2` (celeste) |
| `.aviso` (segunda regla, más abajo) | `#be123c` (rojo oscuro) |
| `.urgente` | `#dc2626 !important` (rojo) |
| `#especial-dos` | `#7c3aed` (violeta) |

La página tiene seis casos, marcados con una letra (A a F).

## 🛠️ Proceso esperado

1. **Predecir.** Antes de abrir la página en el navegador, anotá para cada caso **qué color** tendrá su texto y **por qué**
   (origen, importancia, especificidad u orden).
2. **Comprobar.** Abrí la página con las herramientas del navegador (F12), inspeccioná cada caso y comparalo con tu predicción.
3. **Corregir.** Si una predicción no coincidió, anotá qué criterio te faltó.
4. **Probar en vivo.** En las herramientas, cambiá el color del caso A a `red` y anotá si el archivo `basico-02.css` cambió.

## ✅ Resultado esperado

- ☑️ Seis predicciones con su justificación.
- ☑️ La comprobación de cada caso con las herramientas del navegador.
- ☑️ Una frase que explique si el archivo cambió al editar en vivo.

## 🚧 Restricciones

- 🚫 No modifiques `basico-02.css` ni `basico-02.html`.
- 🚫 Justificá cada predicción con un criterio de la cascada, no con «porque sí».
- 🚫 La comprobación se hace en el navegador, no en el editor.

## 🎓 Resultados de aprendizaje

- RA-4: Usar el navegador para probar y revisar los estilos de una página.
- RA-5: Explicar la herencia y cómo la cascada decide qué estilo se aplica.
