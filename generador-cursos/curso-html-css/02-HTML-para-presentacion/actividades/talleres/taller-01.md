# 🛠️ Taller 01 — Armá tu página de servicios y contacto

## 🎯 Objetivo

Aplicar lo aprendido en la clase: separar el contenido (RA-1), presentar datos en una tabla (RA-2), escribir listas con
sublistas (RA-3), marcar una cita (RA-4) y escribir un formulario con campos de distintos tipos (RA-5 y RA-6).

## 🌍 Contexto

Trabajás solo o en pareja, con **el tema de tu propio sitio** (el mismo del taller de la Clase 01, si lo tenés): un negocio,
un hobby, un club. Usás VS Code (o un editor en línea) y un navegador. No hace falta CSS ni JavaScript. **Usá solo datos
inventados** en el formulario: no se envía a ningún servidor.

## 🪜 Pasos

1. **Creá la página de servicios** (`servicios.html`) con la estructura mínima y un título propio.
2. **Listas.** Escribí una lista no enumerada de al menos tres servicios, con una sublista en uno de ellos, y una lista
   enumerada con los pasos de tu forma de trabajo.
3. **Separadores.** Poné un separador entre los temas de la página.
4. **Tabla.** Armá una tabla de precios con título, encabezados, al menos tres filas de datos y un pie con una aclaración
   que ocupe todas las columnas.
5. **Cita.** Agregá un testimonio (inventado) como cita extensa, con la fuente en el atributo `cite` y la atribución fuera.
6. **Creá la página de contacto** (`contacto.html`) con un formulario `method="get"`, sin `action`, que pida al menos cinco
   datos con **cinco tipos distintos** de campo (por ejemplo: texto, correo, número, una opción entre varias y una casilla),
   con sus etiquetas, `name` y `value`, y un botón de envío.
7. **Probá el formulario**: completalo con datos inventados, enviálo y anotá la dirección que aparece. Probá de nuevo sin marcar
   la casilla y explicá qué dato no viajó.
8. **Revisá** que todas las etiquetas estén cerradas y bien anidadas y que cada `label for` coincida con un `id`.

## 📦 Entregable

La carpeta del proyecto con `servicios.html` y `contacto.html`, y una nota con las dos direcciones que anotaste y la explicación
del paso 7.

## 📋 Criterios de evaluación

- ✔️ Hay una lista no enumerada con una sublista dentro de un `li`, una lista enumerada y separadores entre los temas.
- ✔️ La tabla tiene `caption`, `thead`, `tbody` y `tfoot`, y el pie ocupa todas las columnas.
- ✔️ La cita tiene `blockquote` con `cite` y la atribución fuera, sin usar `cite` para el nombre de una persona.
- ✔️ El formulario usa `method="get"`, sin `action`, con cinco tipos distintos, etiquetas asociadas y `name` en cada campo.
- ✔️ Las dos direcciones anotadas coinciden con lo que hace el formulario y la explicación es correcta.
- ✔️ Solo se usaron datos inventados y no se usó CSS ni JavaScript.
