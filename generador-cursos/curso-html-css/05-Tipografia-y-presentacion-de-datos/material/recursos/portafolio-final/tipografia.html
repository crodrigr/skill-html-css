Una familia con alternativas

Un sitio web nace de una pregunta sencilla: ¿qué querés que haga la persona que lo visita? Si la respuesta es leer, el texto manda; si es comprar, mandan las fotos y los precios. Con esa respuesta clara, el resto de las decisiones se toma casi solo.

Este párrafo pide una tipografía que no existe y, por eso, usa la alternativa de la lista.

Tamaños

Veinte píxeles, con px.

Veinte píxeles, con em.

Veinte píxeles, con rem.

Veinte píxeles, con porcentaje.

Dentro de un contenedor, em se multiplica otra vez.

Dentro de un contenedor, rem no cambia.

Peso y estilo

Peso liviano (300).

Peso negrita (700).

Texto en cursiva.

Altura de línea
