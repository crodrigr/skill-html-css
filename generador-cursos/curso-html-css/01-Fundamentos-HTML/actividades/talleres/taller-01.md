# 🛠️ Taller 01 — Construí tu primer sitio

## 🎯 Objetivo

Aplicar lo aprendido en la clase: preparar tu entorno (RA-2), escribir documentos con buena estructura (RA-3), marcar
texto y comentarlo (RA-4), enlazar páginas (RA-5), incorporar multimedia (RA-6) y organizar con etiquetas
semánticas (RA-7).

## 🌍 Contexto

Trabajás solo o en pareja. Elegís **un tema propio** para tu sitio: un negocio, un hobby, un portafolio, un club. Usás VS
Code (o un editor en línea) y un navegador. No hace falta CSS ni JavaScript. Podés usar las imágenes y el video de
`recursos/portafolio-inicial` o tus propios archivos.

## 🪜 Pasos

1. **Elegí el tema** y anotá en una línea de qué trata tu sitio.
2. **Creá la carpeta** del proyecto y tres archivos: `index.html`, `sobre-mi.html` y `contenido.html` (con el nombre que
   prefieras para la tercera).
3. **Escribí la estructura mínima** de cada página y dale un `title` propio.
4. **Agregá contenido**: títulos, párrafos, al menos una lista y varios formatos (`strong`, `em`, otro más). Dejá al menos
   dos comentarios.
5. **Conectá las páginas**: una navegación que lleve de cada página a las otras dos, un enlace externo que abra en una
   pestaña nueva y un enlace con ancla a una sección de la misma página.
6. **Incorporá multimedia**: una imagen con `alt` y un video con controles; opcionalmente, un `iframe` con un contenido
   que permita ser incrustado.
7. **Reorganizá con semántica**: cabecera, navegación, contenido principal, secciones y pie en cada página. Usá `div`
   solo si hace falta, y explicalo con un comentario.
8. **Probá todo** en el navegador: cada enlace, cada imagen y el video.

## 📦 Entregable

La **carpeta del proyecto** con las tres páginas y sus recursos, que abre sin errores en el navegador.

## 📋 Criterios de evaluación

- ✔️ Las tres páginas tienen estructura mínima completa y etiquetas bien cerradas y anidadas.
- ✔️ Hay títulos, párrafos, una lista, formatos con significado y al menos dos comentarios.
- ✔️ La navegación entre las tres páginas funciona; hay un enlace externo y un ancla.
- ✔️ Todas las imágenes tienen `alt` y se ven; el video tiene controles.
- ✔️ Cada página usa `header`, `nav`, `main`, secciones y `footer`.
- ✔️ No se usó CSS ni JavaScript.
