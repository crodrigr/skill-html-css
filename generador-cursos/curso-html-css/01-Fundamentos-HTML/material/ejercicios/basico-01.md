# 🟢 Básico 01 — Corregí la estructura de un documento

> 🟢 **Nivel:** Básico · 🎓 **Resultados de aprendizaje:** RA-1, RA-2, RA-3

## 🧱 Estado inicial

Mateo Ruiz, fotógrafo de Rosario, escribió su primera página en VS Code, pero el navegador no la muestra como espera.
Este es su archivo `index.html`:

```html
<html>
  <head>
    <meta charset="utf-8">
    <title>Mateo Ruiz | Fotógrafo
  </head>
  <body>
    <h1>Mateo Ruiz</h1>
    <p>Fotógrafo de <em>Rosario</p></em>
    <img src="imagenes/retrato.png" alt="Retrato de Mateo"></img>
  </body>
</html>
```

## 🛠️ Proceso esperado

**Parte A — Corregir.** El documento tiene **cinco errores** de estructura, de sintaxis o de anidación. Encontralos y
escribí el documento corregido.

**Parte B — Clasificar.** Decí si cada elemento va en el `head` o en el `body`: `title`, `h1`, `meta`, `p`, `img`.

**Parte C — Responder.**

1. ¿Qué tipo de lenguaje es HTML: de marcado o de programación?
2. En el documento corregido, ¿quién es el **padre** del elemento `em`?
3. Para ver el archivo en el navegador, ¿con qué extensión tiene que estar guardado?

## ✅ Resultado esperado

- ☑️ Cinco errores identificados y un documento corregido que pase la revisión de estructura.
- ☑️ Los cinco elementos clasificados.
- ☑️ Tres respuestas correctas, de una frase cada una.

## 🚧 Restricciones

- 🚫 No agregues contenido nuevo: solo corregí lo que está mal.
- 🚫 No cambies los textos de la página.

## 🎓 Resultados de aprendizaje

- RA-1: Explicar qué es HTML5 y qué papel cumple en una página web.
- RA-2: Preparar un entorno de desarrollo y ver un archivo HTML en el navegador.
- RA-3: Escribir un documento con estructura válida, sintaxis y anidación, y explicar el DOM.
