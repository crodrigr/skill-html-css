**3. [identificación de resultado]** 🔍
Mirá este código. ¿Qué se ve en el navegador?

```html
<p>Precio: <del>$90</del> <ins>$75</ins></p>
<ul>
  <li>Retrato</li>
  <li>Paisaje</li>
</ul>
```

A. El precio $90 tachado seguido de $75, y una lista con viñetas de dos elementos.
B. El precio $75 tachado seguido de $90, y una lista numerada.
C. Solo la palabra «Precio:», sin números.
D. Una lista numerada con el precio como primer elemento.

_RA: RA-4_

**6. [identificación de resultado]** 🔍

B. Se abre `sobre-mi.html` desde arriba, sin resaltar nada y sin error.
